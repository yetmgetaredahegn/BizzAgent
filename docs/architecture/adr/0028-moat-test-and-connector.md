# ADR-0028: Moat test as a product rule; MCP connector strategy

- **Status:** Accepted
- **Date:** 2026-10-02

## Context

General assistants can do generic chat; competing on chat alone loses.

## Decision

A feature ships only if it uses a moat (verified knowledge, persistent data, network, rails, local access, human experts). An MCP server lets other assistants use BizzAgent's moats.

## Consequences

A focused roadmap and an extra distribution channel. Some easy features are rejected.
