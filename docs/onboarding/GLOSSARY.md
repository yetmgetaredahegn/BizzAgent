# Glossary (product and engineering terms)

> **What this is:** the words we use in code and docs. Business terms in three languages are in the [i18n glossary](../i18n/glossary-am-om-en.md).
> **Who reads it:** everyone.
> **Last reviewed:** 2026-10-02

| Term | Meaning |
|---|---|
| **Artifact** | A versioned document in the Business File (profile, plan, sheet, proposal…) whose fields carry provenance. |
| **Autonomy level** | L0 suggest · L1 draft · L2 act with approval · L3 autopilot within limits. |
| **Business File** | All artifacts of a venture workspace. |
| **Call** | An on-platform opportunity that accepts applications, with a versioned configuration. |
| **Common Application** | Mapping the Business File onto several calls' forms at once. |
| **Concierge** | The supervisor graph that talks to the user and routes to skills. |
| **Consent grant** | A time-limited, revocable permission for a helper, advisor or viewer. |
| **CostTicket** | The UI showing a credit estimate before a paid action. |
| **Country pack** | Cited, human-verified knowledge entries for one country. |
| **Directory entry** | An off-platform funder or programme with submission instructions. |
| **EC / GC** | Ethiopian calendar / Gregorian calendar. |
| **Evidence grade** | The provenance status of a fact as shown to others (Passport, funders). |
| **Inbox** | Where approval and question cards wait for the user. |
| **Mission** | A durable, multi-skill goal run as a LangGraph thread. |
| **Moat test** | A feature must use verified knowledge, persistent data, the network, rails, local access or human experts. |
| **Pack entry** | One knowledge item with sources, verification and a review date. |
| **Passport** | A consented, shareable snapshot of business facts with evidence grades. |
| **Personal space** | The private area of a user (personal finance). Nobody else can read it. |
| **Provenance** | `{status, source, evidence, note}` attached to a value. Statuses: established, unverified, missing, contradictory. |
| **Read-back** | BizzAgent repeats what it understood before saving it. |
| **Readiness Score** | A deterministic score of funding readiness, with the actions that raise it. |
| **Skill** | A LangGraph sub-graph that does one kind of job (numbers, setup, funding…). |
| **Standing instruction** | A user's plain-language rule, stored as an enforced policy. |
| **Verifier** | A check that runs before output reaches the user (grounding, rules, language, policy). |
| **Watcher** | A background job that creates inbox items (deadlines, opportunities, anomalies). |
| **Workspace** | An organisation the user belongs to: explorer, team, business, collective or partner. |
