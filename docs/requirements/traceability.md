# Traceability: requirements → tests

> **What this is:** every SRS requirement ID mapped to the PR that delivers it and the test that proves it.
> **Who reads it:** reviewers, QA. Update the status column in the PR that adds the test.
> **Last reviewed:** 2026-10-02

Status values:

- `planned`: the test file is named here; the test does not exist yet.
- `tested`: the test exists and passes in CI.
- `designed`: the requirement is designed but not scheduled.

Honesty invariants also have named tests; see [testing §3](../engineering/testing-and-evaluation.md#3-honesty-invariants).
